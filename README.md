# Tic Tac Toe Game

This is a simple Tic Tac Toe game implemented with HTML, CSS, and JavaScript.

## How to Play

Open the `index.html` file in a web browser to start playing the game.

## Project Structure

- `index.html`: The main HTML file.
- `styles.css`: The CSS styles for the game.
- `script.js`: The JavaScript logic for the game.
